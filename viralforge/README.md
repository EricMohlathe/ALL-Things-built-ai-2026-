## Why this exists (the 10-second pitch)

The internet is drowning in people *teaching* faceless AI content and starving for a
tool that *does it*. ViralForge is that tool. Five steps, one app:

1. **Niche Finder** — your interests → 5 profitable niches + the best offer for each
2. **Content OS** — a niche → 5 pillars × 3 series + a 30-day post calendar
3. **Viral Script Writer** — a topic → 12 hooks + a 35–45s short-form script
4. **Carousel Builder** — a topic → 7-slide carousel + caption + 10 hashtags
5. **DM Money Funnel** — comments → cash: CTA line + 5 DMs + 3 follow-ups
