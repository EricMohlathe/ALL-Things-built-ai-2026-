## 02 — AUCTION MARKET THEORY (AMT)

### Two-State Model
```
BALANCE (Equilibrium)
  ├─ D-shape profile develops
  ├─ Price rotates around fair value
  ├─ Both buyers and sellers satisfied
  ├─ ~70% of time
  └─ Model 2 (Mean Reversion) applies

IMBALANCE (Directional)
  ├─ One side becomes more aggressive than other can absorb
  ├─ Price moves away to discover new fair value
  ├─ Elongated profile, LVNs crossed rapidly
  └─ Model 1 (Trend Continuation) applies
```

### AMT Core Insight
The market's primary job is to **facilitate trade**, not to trend. Trading breakouts inside balance = ~30% win rate on continuation. Trading reversion inside balance = ~65–70% win rate. This single insight fundamentally changes the approach.

### Market State Classification Checklist
| Factor | Balanced | Imbalanced | Weight |
|--------|---------|-----------|--------|
| Prior day profile shape | D-shape, symmetric | b/P/elongated | ⬛⬛⬛⬛⬛ HIGH |
| Prior day close vs mid | Near midpoint (<20% from mid) | Near extreme (>30% from mid) | ⬛⬛⬛⬛ HIGH |
| Current open vs prior VA | Inside prior VA | Outside prior VA / gap | ⬛⬛⬛⬛⬛ CRITICAL |
| ATR ratio (5-period/20-period) | <0.9 (contracting) | >1.3 (expanding) | ⬛⬛⬛ MEDIUM |
| Opening drive CVD | Oscillating, no direction | Trending strongly one way | ⬛⬛⬛⬛ HIGH |
| LVN density | Few LVNs, clustered volume | Multiple LVNs, thin areas | ⬛⬛⬛ MEDIUM |
| Macro/news context | No major catalyst | Post-news, earnings, FOMC | ⬛⬛⬛ CONTEXT |

**When State is Unclear**: If 3+ factors are ambiguous → Do NOT trade. Wait 15–30 min for clarity.

## 08 — ABSORPTION MECHANICS (Core Concept)

### The 5-Phase Absorption Sequence
1. **Aggressive Order Hits** — Retail/algos send market orders aggressively (e.g., selling). Normally depletes limit orders and price falls.
2. **Limit Orders Replenished** — Institutional player has massive limit buy at this level. Keeps adding limit orders as fast as they're consumed. Price barely moves despite heavy selling.
3. **What You See** — Large sell delta on footprint BUT price NOT moving down. CVD falling but price flat. Delta/price divergence = absorption signature.
4. **Aggressor Exhaustion** — Aggressive sellers run out of conviction or capital. Institutional limit buyer has now accumulated large position.
5. **Reversal** — When aggressive selling stops, accumulated position drives price up sharply.

**Entry**: When aggression pivots (sellers giving up + CVD turning up + large buy prints appearing). Stop: 1–2 ticks below absorption low. Target: Prior POC.

```mql5
    return false;

```

### Module 2 — Market State Detection
```mql5
enum MSTATE { BALANCED, IMBALANCED, UNKNOWN };

MSTATE GetMarketState() {
    double atr5  = iATR(_Symbol, PERIOD_H1, 5, 0);
    double atr20 = iATR(_Symbol, PERIOD_H1, 20, 0);
    double ratio = (atr20 > 0) ? atr5 / atr20 : 1.0;
    
    double pdH = iHigh(_Symbol, PERIOD_D1, 1);
    double pdL = iLow(_Symbol, PERIOD_D1, 1);
    double pdC = iClose(_Symbol, PERIOD_D1, 1);
    double rng = pdH - pdL;
    double fromMid = (rng > 0) ? MathAbs(pdC - (pdH+pdL)/2) / rng : 0;
    
    if (ratio > 1.3 && fromMid > 0.30) return IMBALANCED;
    if (ratio < 0.90 && fromMid < 0.20) return BALANCED;
    return UNKNOWN;
}
```

```mql5
input int    MaxConsecLoss = 3;   // stop after N losses
input bool   ForceClose21h = true; // mandatory session close

int    consecutiveLosses = 0;
double dailyPnL = 0;

double CalcLots(double stopDist) {
    double bal  = AccountInfoDouble(ACCOUNT_BALANCE);
    double risk = bal * RiskPct / 100.0;
    double tv   = SymbolInfoDouble(_Symbol, SYMBOL_TRADE_TICK_VALUE);
    double ts   = SymbolInfoDouble(_Symbol, SYMBOL_TRADE_TICK_SIZE);
    double pv   = (ts > 0) ? tv / ts : 1;
    double lots = risk / (stopDist * pv);
    return NormalizeDouble(MathMax(
        SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MIN),
        MathMin(SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MAX), lots)), 2);
}

bool CanTrade() {
    if (!IsInSession()) return false;
    if (consecutiveLosses >= MaxConsecLoss) return false;
    if (dailyPnL <= -AccountInfoDouble(ACCOUNT_BALANCE)*MaxDailyPct/100) return false;
    if (GetMarketState() == UNKNOWN) return false;
    return true;
}

// Mandatory session close at 21:00 SAST — call in OnTimer()
void SessionCloseCheck() {
    if (!ForceClose21h) return;
    MqlDateTime dt;
    TimeToStruct(TimeCurrent(), dt);
    if (dt.hour == 21 && dt.min == 0) {
        CTrade trade;
        for (int i = PositionsTotal()-1; i >= 0; i--)
            if (PositionGetSymbol(i) == _Symbol)
                trade.PositionClose(PositionGetTicket(i));
    }
}
```

### Module 4 — LVN Level Manager
```mql5
input double PrevPOC = 0.0;   // Prior day Point of Control
input double PrevVAH = 0.0;   // Prior day Value Area High
input double PrevVAL = 0.0;   // Prior day Value Area Low
input double LVN1    = 0.0;   // Low Volume Node 1
input double LVN2    = 0.0;   // Low Volume Node 2
input double LVN3    = 0.0;   // Low Volume Node 3
input double LVNzone = 2.0;   // LVN proximity alert (ticks)

bool IsNearLevel(double price, double level) {
    if (level == 0) return false;
    double dist = MathAbs(price - level);
    return dist <= LVNzone * SymbolInfoDouble(_Symbol, SYMBOL_POINT);
}

bool AtKeyLevel() {
    double ask = SymbolInfoDouble(_Symbol, SYMBOL_ASK);
    return IsNearLevel(ask, LVN1)   || IsNearLevel(ask, LVN2) ||
           IsNearLevel(ask, LVN3)   || IsNearLevel(ask, PrevVAH) ||
           IsNearLevel(ask, PrevVAL) || IsNearLevel(ask, PrevPOC);
}
```
